Your payout is not your sales.

The apps take commission, GST on that commission, coupons you fund, ads and fees, then pay you the rest in a long spreadsheet. Most owners see one number and never see where the rest went.

In one real Swiggy statement we tested, with 28 orders, the owner kept ₹60 of every ₹100 sold. Coupons he funded himself took ₹13. Nothing in the statement said that in one place.

How it works

  1. Add your files

    Your Swiggy payout statement and, if you have it, the Zomato business report. They are read in your browser.

  2. See what you keep

    Where each ₹100 went, and three decisions about coupons, Swiggy against Zomato, and when to push. Each one says what to do, how to measure it, and when to stop.

  3. Save the payout

    A small summary stays on your device: dates and totals, never order details.

  4. Add the next one

    The page shows what changed, which cost moved most, and whether the coupon advice from last time worked.

Private by design

Your files are read inside your browser and never uploaded. Only the sentences on the page, with no order details, can go to an AI model to be reworded, and only if one is set up.

Saving is your choice. A saved payout keeps dates and totals on this device only, and one button deletes everything.

How it is built

Each tool has one job. Code does the money, because a payout figure has to be exact. AI is used where words and language matter, and a code checker watches what it writes.

Claude and Claude Code
Planned and built the app in a loop of plan, build, check and fix, with a written plan and 22 automated tests.
Apify
Collected the public posts, search results and review pages behind the research.
SheetJS
Reads the Swiggy and Zomato files inside your browser.
An AI model
Rewords the advice in English, Hindi or Kannada through one small server function. Code then checks every number it writes against your data and throws out any wording with a number that isn’t there. With no key, the page shows plain English.
GitHub and Vercel
Keep the code and host the site.
Node’s test runner
Checks the maths, the number checker and the memory.

What it can’t do yet

  • It reads Swiggy payout statements. Zomato’s report has no commission or fees, so Zomato take-home is always an estimate.
  • It has been tested on one outlet’s statements. Treat the advice as ideas to test, not conclusions.
  • “Did it work?” covers the coupon decision only, for now.
